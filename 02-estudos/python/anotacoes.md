## Resumo de bolso - Git Bash

1. `cd /c/Users/Matheus/Documents/jornada-dev` — entrar na pasta do projeto
2. `git status` — verificar o estado do repositório
3. `git add .` — adicionar alterações para o próximo commit
4. `git commit -m "mensagem do commit"` — registrar as alterações no repositório local
5. `git push` — enviar as alterações para o GitHub
